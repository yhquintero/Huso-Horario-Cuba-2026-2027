01 · ALCANCE Y EFECTOS

Qué cambia.
Y qué no.

Los archivos añaden o actualizan una definición de zona horaria en el Registro de Windows. Importarlos no equivale a elegirla como zona activa del equipo.

INCLUIDO

Lo que hace el perfil

  • ✓Escribe únicamente en la entrada Cuba Standard Time y su subclave Dynamic DST.
  • ✓Incluye TZI por año: 2026 con Bias 240 y campos de transición vacíos; 2027 con Bias 300 y un StandardDate codificado.
  • ✓La aplicación también puede seleccionar la zona horaria; requiere autorización de administrador para modificar HKEY_LOCAL_MACHINE.
NO INCLUIDO

Lo que no hace

  • —Importar el archivo .reg no selecciona la zona activa ni cambia manualmente el reloj; la aplicación PowerShell sí puede seleccionar Cuba.
  • —El perfil .reg no configura servidores NTP. Al aplicar, la app puede reiniciar W32Time y solicitar una resincronización; también guarda logs, preferencias y respaldos locales y puede crear un acceso directo si se solicita.
  • —No certifica que la regla sea una decisión oficial vigente. Verifica esa información antes de instalar.
RUTA EXACTA MODIFICADA HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Time Zones\Cuba Standard Time También se escribe en la subclave Dynamic DST para las reglas por año.

03 · PROCEDIMIENTO

Un proceso prudente,
paso a paso.

Haz estos pasos en el equipo que quieres configurar. Si es un dispositivo administrado por una empresa, escuela o institución, consulta primero al administrador.

Antes de importarComprueba el SHA-256 y guarda una copia de seguridad. Si algo no coincide, detente.
  1. 01

    Descarga desde el repositorio

    Para instalar manualmente, elige 2_Cuba_2027_Correcto.reg. No uses el archivo 1_Limpiar.reg como instalador: elimina la subclave dinámica.

  2. 02

    Verifica y respalda

    Compara el SHA-256 con el valor publicado. En regedit, si existe la clave Cuba Standard Time, selecciónala y usa Archivo → Exportar; confirma que el rango sea la rama seleccionada. La exportación conserva valores previos, pero al reimportarla no elimina automáticamente valores nuevos. Para una reversión completa, crea un punto de restauración.

  3. 03

    Inspecciona el contenido

    Abre el perfil activo con el Bloc de notas y confirma que solo escribe en la clave Cuba Standard Time y su subclave Dynamic DST. Si aparecen otras rutas, datos de eliminación o contenido inesperado, no lo importes.

  4. 04

    Importa con confirmación

    Abre el archivo con el Editor del Registro y revisa cada aviso de Windows. Acepta solo si el archivo y el nombre del perfil coinciden con lo que elegiste. Se requieren permisos de administrador.

  5. 05

    Selecciona la zona horaria

    El perfil .reg solo incorpora la definición; luego selecciona Cuba en Configuración → Hora e idioma → Fecha y hora, si corresponde. La aplicación .ps1 también selecciona la zona al aplicar; revisa su código y la política de ejecución antes de usarla.

  6. 06

    Comprueba sin cambiar el reloj

    En una terminal puedes ejecutar tzutil /g para consultar la zona activa. No cambies manualmente la fecha y la hora para probar transiciones.

04 · SEGURIDAD Y VERIFICACIÓN

Comprueba el archivo
antes de confiar.

El cálculo SHA-256 se ejecuta en este navegador. El archivo que selecciones no se envía a un servidor. Una coincidencia confirma que sus bytes son idénticos al perfil publicado aquí.

01

Integridad del archivo

Compara la huella completa de 64 caracteres, no solo el nombre o el tamaño. Si no coincide exactamente, no lo importes.

02

Alcance explícito

El perfil activo escribe valores en la zona de Cuba y su subclave dinámica. El archivo de limpieza, en cambio, elimina toda esa subclave; inspecciona siempre el archivo antes de importarlo.

03

Respaldo recuperable

Exporta la clave, si existe, para conservar sus valores previos y crea un punto de restauración para una reversión completa. Reimportar un .reg de respaldo no elimina automáticamente los valores nuevos.

04

Sin firma digital

Este proyecto publica hashes de integridad, pero los archivos no están firmados digitalmente. Un hash no demuestra por sí solo quién publicó el archivo.

Valores principales

El archivo activo contiene TZI de 44 bytes para cada año. La entrada 2026 tiene Bias=240 (desfase base UTC−04:00) y campos de transición vacíos, por lo que no codifica el cambio del 1 de noviembre de 2026. La entrada 2027 tiene Bias=300 (UTC−05:00) y un StandardDate que decodifica al primer domingo de noviembre a la 01:00 —7 de noviembre de 2027—; su DaylightDate está vacío. Esto describe los bytes, no certifica el resultado efectivo en todas las versiones de Windows ni confirma una fecha oficial.

Prueba automatizada de alcance

El repositorio incluye tools/verify_registry.py: valida el alcance de ambos archivos, los TZI de 2026/2027, la coincidencia de bytes con la aplicación PowerShell y los SHA-256 publicados. Es una comprobación estática; no ejecuta la app ni certifica el calendario. Se ejecuta con python3 tools/verify_registry.py.

05 · PREGUNTAS FRECUENTES

Respuestas
sin letra pequeña.

Si administras un equipo de trabajo o una red institucional, confirma el procedimiento con soporte técnico antes de importar cambios al Registro.

¿El perfil .reg cambia automáticamente la hora del equipo?

No selecciona la zona activa ni fija manualmente la hora. Incorpora o actualiza la definición de Cuba Standard Time; después debes elegir la zona desde la configuración de Windows si esa es la que corresponde.

¿Esta configuración está aprobada oficialmente?

Este es un proyecto independiente y no representa a Microsoft ni a una institución del Gobierno de Cuba. Los archivos contienen datos horarios propuestos para 2026 y 2027; comprueba la disposición oficial vigente antes de utilizarlos.

¿Para qué sirve 1_Limpiar.reg?

Elimina completamente la subclave Dynamic DST, incluidas entradas de años que el perfil activo no modifica. No es necesario para instalar ni para revertir el perfil y no debe importarse salvo que quieras explícitamente eliminar toda esa subclave y tengas un respaldo apropiado.

¿Cómo vuelvo atrás si ya importé el archivo?

La exportación previa permite restaurar valores anteriores, pero importar ese .reg no elimina automáticamente valores que se hayan añadido. Para revertir completamente el cambio usa el punto de restauración o el procedimiento de recuperación de tu organización; no borres claves manualmente si no conoces sus efectos.

¿Por qué Windows solicita permisos de administrador?

La clave de zona horaria está bajo HKEY_LOCAL_MACHINE, que afecta a la configuración del equipo. No continúes si no tienes autorización para administrarlo o si el aviso de Windows no corresponde al archivo que esperabas.

¿Qué hago si la huella no coincide?

No importes el archivo. Elimínalo, vuelve a descargarlo directamente desde el repositorio y repite la comparación. Si sigue sin coincidir, solicita una revisión mediante el canal de seguridad del proyecto.

Verifica. Respalda. Luego decide.
